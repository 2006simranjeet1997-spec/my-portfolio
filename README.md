
# My Portfolio

A personal developer portfolio built with Next.js, Tailwind CSS, and Motion.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- Next.js
- React.js
- Tailwind CSS
- Motion
- Lucide React
- GitHub REST API

## Features

- Personal introduction
- About Me section
- Skills showcase
- Featured projects
- GitHub projects integration
- Responsive design
- Smooth animations
